# Cybershake-E.Workflow

This repository is a report on the complete workflow established for the usage of SCEC's research project, Cybershake. Detailing necessary steps and optimizations for a direct usage and extraction of the seismograms for a machine learning operation. Model integrationwas was studied for Seismic Hazard Prevention Protocols (SHPP).

Background:
